Thermodynamics · JEE Main 2026, 2 Apr Shift 1

Heat is supplied to a diatomic gas at constant pressure. Then the ratio of ΔQ : ΔU : ΔW is ________.

Choose your answer

Key idea

At constant pressure ΔQ : ΔU : ΔW = Cp : Cv : R. For a diatomic gas Cv = 5R/2 and Cp = 7R/2, so the ratio is 7 : 5 : 2.

Common mistake

Using monatomic values (Cv = 3R/2), which gives 5 : 3 : 2.
