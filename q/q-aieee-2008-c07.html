AIEEE 2008 Chemistry: Chemical Equilibrium

Multiple choice, one correct option Memory based Chemical Equilibrium

For the following three reactions $a, b$ and $c$, equilibrium constants are given: a. $\mathrm{CO(g) + H_2O(g) \rightleftharpoons CO_2(g) + H_2(g)}$; $\mathrm{K_1}$ b. $\mathrm{CH_4(g) + H_2O(g) \rightleftharpoons CO(g) + 3H_2(g)}$; $\mathrm{K_2}$ c. $\mathrm{CH_4(g) + 2H_2O(g) \rightleftharpoons CO_2(g) + 4H_2(g)}$; $\mathrm{K_3}$ Which of the following relations is correct?

  1. (1)

    $\mathrm{K_1\sqrt{K_2} = K_3}$

  2. (2)

    $\mathrm{K_2\,K_3 = K_1}$

  3. (3)

    $\mathrm{K_3 = K_1\,K_2}$

  4. (4)

    $\mathrm{K_3 \cdot K_2^3 = K_1^2}$

Show answer

Option (3) is correct.
